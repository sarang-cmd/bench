# Needs human proofreading

The three booklets in the folder above were transcribed from the PDFs in the
request (AA HL 2023 V1.0, Physics 2025 V1.2, Chemistry 2025 V1.1) into plain
text, in Bench's own words where a line explained something, and directly where
a line is a formula.

**Nobody has read them against the official documents line by line yet.** Treat
a formula you have not checked as unchecked: the first line of each booklet says
so on the calculator too, and any line that disagrees with the official booklet
is wrong here.

What to check first:

- every constant (Physics page 1, Chemistry page 1, both worth a mark on their
  own)
- the HL-only sections, which the PDF prints on shaded pages and which are the
  easiest to skip: AA HL topics 3.15, 4.13, 5.19; Physics 9.1, 11.1, 12.1
- the options pages at the end of the Chemistry booklet, which this transcription
  only names rather than fills in
- anything with a quotient: a dropped bracket changes the formula

Fix a line by editing the `.txt` in the folder above; nothing in the add-in
needs to change. The renderer only knows `#`, `##`, `###` at the start of a
line and one space after them.
